这篇笔记整理自 Codex 的三段会话：LLM 项目里的「解释ResNet」，reading 项目里的「超连接论文解读」「解读mHC提出原因」，以及同一篇 HC 论文附录里的「解释PostNorm证明」。

这条线可以概括成三次问题升级：

1. ResNet：网络太深以后，怎样让信号和梯度至少有一条直接通路？
2. Hyper-Connections：只有一条残差流是否限制表达能力？能不能扩宽残差流并学习流间交互？
3. mHC：残差流之间的交互变自由以后，怎样防止几十层矩阵连乘把信号放大或压没？

三者不是简单的「残差连接越来越复杂」，而是在**表达能力**和**数值稳定性**之间不断重新找平衡。

## 一、ResNet：先给深层网络一条恒等通路

普通的前馈网络希望直接学习一个映射 $H(x)$。ResNet 改成学习残差

```math
y=x+F(x)
```

其中 $x$ 通过 shortcut 直接传到后面，$F(x)$ 是卷积层等模块要学习的「相对输入需要做出的改变」。

这样做最直接的好处是：如果某一组层暂时不需要改变表示，只要让 $F(x)\approx0$，整个块就近似恒等映射。普通网络要学会「什么都不做」，反而需要把多层权重精确调成恒等映射；ResNet 把这个任务变简单了。

更关键的是反向传播。设

```math
y=x+F(x)
```

则

```math
\frac{\partial y}{\partial x}
=I+\frac{\partial F(x)}{\partial x}
```

梯度里始终有单位矩阵 $I$ 这一项。即使 $\partial F/\partial x$ 很小，shortcut 仍然提供一条直接回传的路径。把很多块展开，深层输出可以写成

```math
x_L=x_l+\sum_{i=l}^{L-1}F_i(x_i)
```

浅层输入不需要经过每一层的变换矩阵反复相乘，就能出现在深层表达中。

但这里必须加一个边界：**残差连接改善优化条件，不保证梯度绝对不消失。** 多个残差块的雅可比矩阵仍然会相乘；LayerNorm、初始化、激活函数、学习率和数据分布都会影响最终稳定性。ResNet 的贡献是给深层网络增加了一条结构上的「低阻力通路」，不是给所有深层网络发一张免死金牌。

另一个工程细节是形状匹配。如果 $x$ 和 $F(x)$ 的通道数或空间尺寸不同，shortcut 不能直接相加，需要使用 $1\times1$ 卷积或池化做投影：

```math
y=F(x)+W_sx
```

## 二、从 ResNet 到 Transformer 的残差流

Transformer 继承了同样的思想。一个子层可以写成

```math
h'=h+\operatorname{Attention}(h)
```

再接一个前馈网络：

```math
h_{\text{out}}=h'+\operatorname{FFN}(h')
```

具体顺序取决于 Pre-Norm 还是 Post-Norm：

- Pre-Norm：先归一化，再进入 Attention/FFN，最后加回原输入。
- Post-Norm：先做子层和残差相加，再对结果做归一化。

Pre-Norm 的恒等通路更直接，深层训练通常更稳定；Post-Norm 的表达和归一化位置不同，但也有自己的训练问题。HC 论文后来给了一个很有用的视角：**Pre-Norm 和 Post-Norm 都可以看成不可训练的超连接（hyper-connections）**，只是连接矩阵被固定住了。

对 Pre-Norm，在扩展率 $n=1$ 时，可以把它写成一个固定的连接矩阵；对 Post-Norm，因为归一化依赖输入和输出的方差、协方差，连接系数会随数据变化，但仍然是不可训练的结构系数。

这说明 HC 并不是突然发明了一种完全无关的结构，而是把「残差连接本身」当成了一个可以学习和扩展的对象。

## 三、Hyper-Connections：把一条残差流扩成多条

标准残差流只有一条 $C$ 维向量：

```math
x_{l+1}=x_l+F_l(x_l)
```

Hyper-Connections 把它扩展成 $n$ 条并行流：

```math
X_l\in\mathbb{R}^{n\times C}
```

然后用三个映射控制信息流：

- $A_m$：从多条残差流中读取信息，形成当前子层的输入。
- $B$：把子层计算出的新特征写回各条残差流。
- $A_r$：在残差流之间做混合，决定旧信息如何传到下一层。

一个便于理解的抽象写法是

```math
X_{l+1}=A_rX_l+B^\top F_l(A_m^\top X_l)
```

其中 $A_r\in\mathbb{R}^{n\times n}$，$A_m\in\mathbb{R}^{n\times1}$，$B\in\mathbb{R}^{1\times n}$。当 $n=1$、$A_r=1$、$A_m=B=1$ 时，它就退化成普通残差连接：

```math
x_{l+1}=x_l+F_l(x_l)
```

HC 的表达能力来自 $A_r$：它可以让不同残差流交换信息，也可以让某些流更多保留旧信息、某些流更多接收新特征。论文的主要实验使用扩展率 $n=4$。

### 静态 HC 与动态 HC

Static HC 的 $A_m,A_r,B$ 是训练得到的固定参数。训练完成后，不管输入是什么，同一层的连接规则都一样。

Dynamic HC 则让连接权重依赖当前输入。以读取映射为例：

```math
A_m(H)=s_\alpha\odot\tanh(HW_m)+A_m
```

右边第一项是根据当前隐藏状态生成的动态调整，第二项是静态基础权重。动态版本还做了三件事来稳定训练：

- 先对 $H$ 做归一化，减少特征尺度变化。
- 用 $\tanh$ 把动态调整限制在有界范围。
- 用较小的初始缩放因子，让模型开始时接近静态 HC，再逐渐学习动态调整。

DHC 的完整流程可以概括为：

1. 根据当前隐藏状态生成动态连接权重。
2. 用这些权重从多条残差流中读取当前子层的输入。
3. 经过 Transformer 子层计算新特征。
4. 把新特征写回，并混合旧的残差流。

### 初始化为什么重要

HC 引入了这么多连接参数，如果一开始就随机初始化，可能直接破坏原本稳定的 Pre-Norm 残差结构。论文的初始化策略是让 HC 在训练开始时等价于 Pre-Norm：

- 动态参数 $W_\beta,W_m,W_r$ 初始化为 0，于是动态调整项为 0。
- $A_r=I$，各条残差流先不交叉混合。
- $B=\mathbf{1}^{1\times n}$，每条流接收相同的新特征。
- $A_m=e_{k\bmod n}$，不同层轮流选择一条流；但初始化时多条流是同一个输入的副本，所以选哪一条都一样。

这样，模型先从一个稳定的单流 Pre-Norm 网络出发，再通过训练逐渐学会是否要扩宽信息通路。这是一个很典型的「先保持基线行为，再增加自由度」的设计。

## 四、HC 的风险：矩阵连乘会把小偏差放大

HC 的直接残差路径不再是一个固定的单位矩阵，而是多个 $A_r$ 的乘积：

```math
X_L=\left(\prod_{i=l}^{L-1}A_{r,i}\right)X_l+\text{子层贡献}
```

如果每一层的 $A_r$ 都稍微把某个方向放大 1.1 倍，60 层后就是 $1.1^{60}\approx304.5$；如果每层缩小到 0.9，60 层后只剩 $0.9^{60}\approx0.0018$。这只是一个标量示意，但说明了核心问题：**单层看起来很小的增益，经过深度方向的复合，可能变成很大的前向信号增益或反向梯度增益。**

HC 论文报告过这种现象：在 27B 模型的训练中，HC 的复合映射最大增益曾接近 3000，并在约 12k 步附近出现明显的损失异常。HC 获得了更强的流间交互能力，但也失去了 ResNet 那种「残差路径至少包含一个单位映射」的严格保证。

这就是 mHC 要解决的问题。
## 五、mHC：不取消交互，而是把交互约束在稳定流形上

mHC 的全称是 **Manifold-Constrained Hyper-Connections**。它的核心选择不是把 $A_r$ 固定成单位矩阵，也不是粗暴地裁剪矩阵元素，而是要求 $A_r$ 属于一个具有稳定性保证的集合：**双随机矩阵（doubly stochastic matrix）**。

一个 $n\times n$ 矩阵 $P$ 如果满足

```math
P_{ij}\ge0,\qquad
P\mathbf{1}=\mathbf{1},\qquad
\mathbf{1}^\top P=\mathbf{1}^\top
```

就称为双随机矩阵。直观地说：

- 所有元素非负。
- 每一行的和等于 1。
- 每一列的和也等于 1。

所有这样的矩阵构成的集合叫 Birkhoff 多面体。它不是把矩阵固定死，而是把矩阵限制在一个「不会任意放大信号」的流形上。

### 为什么双随机约束能稳定深层传播

双随机矩阵有几个很适合残差流的性质。

第一，单层不会任意放大信号。由行和、列和都为 1，可以得到

```math
\|P\|_2\le\sqrt{\|P\|_1\|P\|_\infty}=1
```

因此对任意向量 $v$，都有

```math
\|Pv\|_2\le\|v\|_2
```

第二，多个双随机矩阵相乘，结果仍然是双随机矩阵。因此

```math
P_{\text{total}}=A_{r,L-1}\cdots A_{r,l}
```

不会因为层数增加而失去稳定性约束。

第三，跨残差流的特征总和与均值受到保护：

```math
\mathbf{1}^\top Pv=\mathbf{1}^\top v
```

这意味着 mHC 允许不同流之间混合，但不允许整体均值被这个残差映射任意放大或缩小。注意，双随机矩阵并不保证每条流各自不变，也不保证流间差异一定缩小；它约束的是整体和与谱增益。

### 一个两条流的例子

假设两条残差流上的标量信号是

```math
x=\begin{bmatrix}10\\0\end{bmatrix}
```

混合矩阵为

```math
P=\begin{bmatrix}0.8&0.2\\0.2&0.8\end{bmatrix}
```

则

```math
Px=\begin{bmatrix}8\\2\end{bmatrix}
```

信息从第一条流混合到了第二条流，但两条流的总和仍然是 10。每一行、每一列的和都是 1，因此它不会把整体信号放大。这个例子说明 mHC 的设计目标：**允许交换，不允许任意缩放。**

## 六、mHC 怎么把矩阵投影到双随机集合

神经网络直接输出的矩阵 $\tilde A_r$ 一般不是双随机矩阵。mHC 使用 Sinkhorn-Knopp 迭代做投影：

1. 对原始 logits 做指数变换，得到全正矩阵：

```math
M^{(0)}=\exp(\tilde A_r)
```

2. 交替做行归一化和列归一化：

```math
M^{(k+1)}=\operatorname{NormalizeRows}\left(\operatorname{NormalizeCols}(M^{(k)})\right)
```

3. 重复若干次后，得到近似的双随机矩阵：

```math
A_r=\operatorname{SinkhornKnopp}(\tilde A_r)
```

论文实验中使用了 20 次迭代。因此实际得到的是近似双随机矩阵，不是严格数学意义上的精确投影；这也是为什么论文报告的最大复合增益约为 1.6，而不是严格等于 1。

除了 $A_r$，mHC 还对读取和写入映射做非负约束：

```math
A_m=\sigma(\tilde A_m),\qquad
B=2\sigma(\tilde B)
```

其中 $\sigma$ 是 Sigmoid。这样做是为了减少正负系数相互抵消造成的信号抵消问题。可以看到，mHC 不是只给残差矩阵加一个 normalization，而是对「读入、写回、流间混合」三条路径都做了有针对性的约束。

## 七、mHC 的工程代价与实验结果

数学上更稳定，不代表训练系统里没有代价。扩展残差流会增加：

- 激活值和中间矩阵的显存占用。
- 数据读写量和内存带宽压力。
- 流水线并行中的通信量。
- Sinkhorn 迭代和额外矩阵乘法的计算开销。

论文配套使用了 kernel fusion、重计算和 DualPipe 通信/计算重叠等工程优化。在扩展率 $n=4$ 的大规模训练中，额外训练时间开销约为 6.7%。

实验结果方面，论文在 27B MoE 模型上比较了 Baseline、HC 和 mHC。最醒目的稳定性结果是：HC 的复合映射最大增益接近 3000，而 mHC 降到约 1.6，改善了约三个数量级。下游任务上，mHC 在八个基准中的七个超过 HC，例如：

- BBH：$48.9\to51.0$
- DROP：$51.6\to53.9$
- GSM8K：$53.2\to53.8$
- MMLU：$63.0\to63.4$
- MATH：$26.4\to26.0$，这一项略低于 HC

这些数字要带着实验条件读：它们是论文特定模型、数据、评测设置下的结果，不是「mHC 在所有任务上必然更好」的证明。更准确的结论是：**mHC 在显著改善深层稳定性的同时，基本保留了 HC 的性能收益，并在多数任务上进一步提升。**

## 八、ResNet、HC、mHC 的关系

可以用一句话概括三者：

- ResNet：用固定的恒等 shortcut 给深层网络一条稳定通路。
- HC：把一条残差流扩成多条，并学习流间的读取、写回和混合。
- mHC：保留 HC 的流间交互，但把混合矩阵约束到双随机流形，防止深层复合增益失控。

它们不是替代关系，而是同一个设计空间里的不同取舍：

- **ResNet**：一条残差流加恒等连接，重点是稳定传播。
- **HC**：扩宽成多条残差流，并学习读入、写回和流间混合。
- **mHC**：保留多条流和混合能力，但把混合矩阵约束为双随机矩阵。

一个容易误解的点是：mHC 并不是「残差连接变弱了」。它仍然保留多条流和流间交互，只是给这种交互加了一个数学上可控的边界。它牺牲的是一部分任意矩阵的可表达性，换来的是深层前向/反向传播的稳定性。

另一个容易误解的点是：双随机约束不等于每条流都被固定住。它允许流之间充分混合，甚至可以让原本集中在一条流上的信息扩散到其他流；它约束的是整体均值和谱增益，而不是每个坐标的瞬时值。

## 九、这条演进线真正说明了什么

ResNet 解决的是「深层网络至少要学会不变得更差」；HC 解决的是「残差流能不能承载更丰富的信息交互」；mHC 解决的是「增加交互以后，怎样不让深层优化重新失控」。

这背后其实是一个反复出现的工程模式：

> 先增加结构自由度，获得表达能力；再给自由度加一个可证明的约束，把训练重新拉回稳定区域。

ResNet 的自由度是「学习残差函数」，约束是恒等 shortcut；HC 的自由度是「学习多条流之间的连接」，代价是失去严格恒等保证；mHC 的自由度仍然是「学习流间连接」，但把连接矩阵限制在双随机流形上。

如果只记一句话：**mHC 的关键不是把残差连接做复杂，而是把「复杂连接」放进一个不会随深度失控的数学集合里。**
