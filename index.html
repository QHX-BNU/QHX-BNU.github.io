02 / Research

Selected research.

A research result on LLM simulation, model capability mismatch, and systematic behavioral bias.

ACL 2026 · Findings

One LLM Does Not Simulate All Students

Ability-Aware Student Simulation via Cognitive Diagnosis Guided LLM Assignment

A single high-capability LLM does not faithfully represent a heterogeneous population. We identify an ability-dependent simulation bias and propose an ability-aware assignment framework that matches different simulated users with more suitable LLM backbones using cognitive diagnosis signals.
