02 / Research

Selected research.

ACL 2026 · Findings

One LLM Does Not Simulate All Students

Ability-Aware Student Simulation via Cognitive Diagnosis Guided LLM Assignment

We study the systematic bias created when a single high-capability LLM is used to simulate students across different ability levels, and introduce an ability-aware framework that uses cognitive diagnosis to match students with suitable LLM backbones.
